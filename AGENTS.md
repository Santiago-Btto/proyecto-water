# Preferencias de colaboración

- Ante la primera solicitud de cada tema nuevo —uno que no sea continuación directa de lo que el usuario venía pidiendo— confirmá brevemente si entendiste la idea antes de iniciar cambios que puedan alterar el funcionamiento de la aplicación. En los seguimientos del mismo tema (por ejemplo, correcciones, pruebas, versión, commit o push), continuá normalmente salvo que haya una duda importante.
- Cuando el usuario confirme que avance, implementá el pedido con cuidado, priorizando claridad, datos correctos y una experiencia simple para quien usa el reparto.
- Al terminar, explicá de forma breve qué quedó hecho y si la verificación técnica fue correcta.
